# Original whiteboard sources

Five unmodified JPEGs from Tilek Zhumabek's lecture share, dated 2026/09/15 16:35:
https://openapi3.miceasy.com/jeewx/whiteboardQRShareController.do?gotoSharePage&id=2c942271a0712ffe01a0a434a7765bbc

Export numbers are identifiers, not teaching order:

- 001: mixed board — positions/displacement, unit vectors, components, scalar derivation.
- 002: projectile motion.
- 003: inclined plane.
- 004: classification, constant velocity, constant acceleration.
- 005: arithmetic pairing and the vector derivation.

The deck uses CSS viewports to show selected regions of these files. Supporting
diagrams and clarifications are authored separately; no original handwriting
has been erased or regenerated. In particular the exact interval-average sum
replaces the ambiguous instantaneous-velocity sum in the original board.
